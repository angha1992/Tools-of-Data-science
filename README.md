# 🛠️ Tools of Data Science

## 📌 Overview

This repository contains notes and practical information about commonly used tools in the Data Science ecosystem.

It is a learning resource covering tools used for data analysis, visualization, machine learning, deep learning, and development.

## 🧰 Tools Covered

- 🐍 Python
- 📊 Pandas
- 🔢 NumPy
- 📈 Matplotlib
- 🎨 Seaborn
- 🤖 Scikit-learn
- 🧠 TensorFlow
- 📓 Jupyter Notebook
- 💻 VS Code
- 🌐 Streamlit
- 📊 Power BI
- 🗄️ SQL
- 🔧 Git & GitHub

## 🎯 Purpose

The goal of this repository is to understand the purpose, features, and practical applications of different tools used throughout the Data Science workflow.

## 📚 Topics

- Data Collection
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Machine Learning
- Deep Learning
- Natural Language Processing
- Data Analytics
- Model Deployment
